# 레시퐁

유튜브·인스타 요리 링크를 **사진 한 장 + 재료 + 순서**로 정리해 두는 지인용 레시피 웹앱입니다. 운영비 0원을 목표로 Cloudflare 무료 플랜과 Gemini 무료 티어 위에서 돌아갑니다.

## 할 수 있는 일

| 기능 | 설명 |
|---|---|
| 사진 + 레시피 | 사진을 맨 위에, 설명과 재료, 만드는 법, 팁을 그 아래에 보여 줍니다. 사진은 직접 찍어 바꿀 수 있습니다. |
| 링크로 정리 | 유튜브는 설명란, 작성자 고정 댓글(YouTube Data API 키가 있을 때) 순서로 레시피를 찾고, 둘 다 없으면 Gemini가 영상을 직접 봅니다. 인스타는 캡션(인스타그램이 Cloudflare 서버 요청을 막아서, 폰서버 도우미가 없으면 캡션을 붙여넣는 화면으로 넘어갑니다), 일반 레시피 사이트는 구조화 데이터(JSON-LD)나 본문을 읽습니다. 글을 붙여넣어도 됩니다. |
| 없는 재료 대체 | 재료를 눌러 "없음"으로 표시하면 대체 재료와 양을 추천합니다. 고른 대로 새 버전에 반영합니다. |
| 냉장고 재고 | 냉장고·냉동실처럼 여러 곳에 재료와 양을 저장합니다. "달걀 10개, 우유 1L, 대파"처럼 한 줄로 넣고 양은 몰라도 됩니다. 같은 재료는 단위를 맞춰 더합니다. |
| 요리하면 차감 | 요리 모드의 [완성]이나 [다 만들었어요]를 누르면 쓴 만큼(인분 반영) 냉장고에서 빼고, 다 쓴 재료는 지웁니다. 되돌리기 가능. |
| 냉장고 파먹기 | 모든 냉장고 재료를 합쳐 내 레시피 중 바로 만들 수 있는 것부터 보여 줍니다(AI 안 씀). 원하면 AI가 새 요리 3가지를 추천합니다. |
| 식단표 | 오늘부터 7일 보기와 달력 보기. 끼니마다 레시피나 "외식" 같은 메뉴를 올리고, 식단에 필요한데 냉장고에 없는 재료를 장보기 목록으로 모아 줍니다. |
| 요리 용어 풀이 | 단계 속 "송송 썰기", "투명해질 때까지" 같은 말을 누르면 풀이와 유튜브 검색 링크를 보여 줍니다(AI 안 씀). |
| 내 입맛 버전 | "더 맵게", "덜 짜게"처럼 AI로 고치거나 직접 수정합니다. 원본은 남고 버전 기록에서 언제든 되돌릴 수 있습니다. |
| 요리 모드 | 큰 글씨로 한 단계씩 보여 주고, 화면 꺼짐을 막고, 단계 속 시간으로 타이머를 켭니다. |
| 앱 설치·공유하기 | 휴대폰에 설치(PWA)하면 유튜브·인스타 앱의 "공유하기"로 링크를 바로 보낼 수 있습니다. |

## 가입과 사용량

- 누구나 이메일로 가입할 수 있습니다. 가입하면 **인증 메일**이 가고, 링크를 눌러야 쓸 수 있습니다(Gmail 앱 비밀번호나 Resend 키를 넣었을 때). 비밀번호를 잊으면 메일로 다시 정할 수 있습니다.
- **지인**과 **관리자**는 사용량 제한이 없습니다. 지인이 가입한 이메일을 알려 주면 **관리 → 사용자 → 이메일로 권한 바꾸기**에 넣고 [지인으로]를 누르면 됩니다. 아직 가입 전인 이메일이면 예약해 두었다가, 그 이메일로 가입해 인증을 마치는 순간 지인이 됩니다.
- **일반 계정**은 맛보기 수준으로 하루 횟수가 정해져 있습니다(나중에 멤버십으로 늘릴 예정). 기본값은 **링크 가져오기 3회, AI 기능 3회**(대체 재료, 입맛대로 바꾸기, 냉장고 추천)이고, 그 밖에 영상 분석은 20분 이하 영상만, 사진 20장, 레시피 저장·수정 60회, AI 요청은 1분에 8회까지입니다. 레시피는 300개, 사진은 모두 200장까지 보관합니다.
- 과다 사용으로 **제한**된 계정은 링크 1회, AI 1회로 줄어듭니다.
- 화면에는 남은 횟수가 늘 보이고, 다 쓰면 버튼이 비활성으로 바뀝니다. 직접 작성·수정, 냉장고의 내 레시피 찾기처럼 AI를 쓰지 않는 기능은 횟수와 상관없이 쓸 수 있습니다.
- 일반 계정들이 함께 쓸 수 있는 AI 몫은 하루 예산의 50%입니다. 나머지는 지인 몫으로 남겨 둡니다.
- 본인이 한도를 넘거나 너무 빨리 보내서 거절된 요청이 하루 20번 쌓이면 자동으로 **제한**(한도 대폭 축소), 80번이면 **차단**합니다. 전체 무료 몫이 찼거나 영상이 길어서 거절된 경우는 세지 않습니다.
- 레시피가 아닌 글처럼 AI를 부른 뒤 실패한 가져오기는 횟수를 돌려주지 않습니다. 캡션을 못 읽는 등 AI를 부르기 전에 멈춘 경우는 돌려줍니다.
- 가입은 IP당 하루 5번, 로그인 시도는 15분에 10번까지입니다. 봇이 채우는 숨은 칸이 있고, 원하면 Cloudflare Turnstile도 켤 수 있습니다.
- 위 숫자는 모두 **관리 → 사용량·한도**에서 바꿀 수 있습니다.

## 구조

```
[휴대폰 브라우저 / 설치한 앱]
        │
        ▼
Cloudflare Worker (하나로 화면 + API)
  ├─ D1: 사용자, 레시피, 버전 기록, 분석 캐시, 사용량
  ├─ KV: 사진 (R2를 연결하면 R2)
  ├─ AI: Gemini 3.8 Flash → 3.5 Flash-Lite → 3.1 Flash-Lite → Groq → Workers AI → OpenRouter
  │      (모델마다 무료 한도가 따로라 차례로 넘어감, 영상 분석은 Gemini만)
  ├─ 같은 링크는 한 번만 분석하고 모든 사용자가 결과를 함께 씀
  │  (사용자가 붙여넣은 글로 만든 결과는 함께 쓰지 않음)
  └─ 인스타 링크 → (선택) 폰서버 도우미 → 캡션
```

- 사진은 Workers KV에 저장합니다(카드 등록 없이 1GB 무료). R2(10GB)는 활성화할 때 카드 등록을 요구해서 기본값에서 뺐고, `wrangler.jsonc`의 R2 주석을 풀면 R2를 씁니다. 레시피에 붙지 않은 사진은 매일 새벽 정리합니다.
- 무료 D1은 DB 하나에 500MB까지라서, 레시피 크기와 버전 보관 수(원본 + 최근 19개)에 상한을 두었습니다.
- 사진은 폰에서 1280px, 1MB 이하로 줄여서 올립니다. 무료 Worker는 요청당 CPU가 10ms라서 서버에서 줄이지 않습니다.
- 비밀번호는 PBKDF2(2만 회)와 서버 비밀값(pepper)으로 저장합니다. 무료 플랜 CPU 한도 안에 들어가는 강도입니다.

## 로컬에서 실행

```sh
npm install
cp .dev.vars.example .dev.vars        # AI_MOCK=1이면 키 없이 예시 응답으로 화면을 볼 수 있어요
npm run db:migrate:local
npm run dev                            # http://localhost:5173
```

실제 AI로 시험하려면 `.dev.vars`에 `GEMINI_API_KEY`를 넣고 `AI_MOCK=0`으로 바꿉니다.

점검:

```sh
npm test            # 레시피 정리·링크 판별·재료 매칭 등 단위 테스트
npm run typecheck
npm run smoke       # 개발 서버를 켠 상태에서 가입부터 한도·차단까지 전체 흐름 점검 (AI_MOCK=1, MAIL_MOCK=1 필요)
```

## 배포

처음 한 번:

```sh
npm run setup
```

질문에 차례로 답하면 됩니다. 키를 미리 넘길 수도 있습니다: `npm run setup -- --admin 내이메일@example.com --gemini 내-Gemini-키 --mail-from "레시퐁 <내계정@gmail.com>" --gmail-app-password 앱비밀번호` (명령줄에 넣은 키는 셸 기록에 남습니다).

`setup`이 하는 일은 다음과 같습니다. 다시 실행해도 이미 있는 것은 건드리지 않습니다.

0. 로그인한 Cloudflare 계정을 보여 주고 이 계정에 배포할지 묻습니다. 아니라고 하면 **이 폴더에서만 쓰는 로그인**을 따로 만듭니다(`.env`의 `XDG_CONFIG_HOME`이 `.wrangler-home/`을 가리킴). 컴퓨터에 로그인된 다른 계정은 그대로 남고, 이 폴더에서 실행하는 `wrangler`만 새 계정을 씁니다. 고른 계정 ID는 `wrangler.jsonc`의 `account_id`에 적어, 다른 계정으로 로그인한 채 배포해도 엉뚱한 곳에 올라가지 않게 합니다.
1. D1 데이터베이스와 사진용 KV를 만들고 `wrangler.jsonc`에 ID를 적습니다. 이 ID는 비밀이 아니니 커밋해 두세요(자동 배포에 필요).
2. 빌드하고, 표를 만들고, 배포합니다. 새 계정이면 이때 `workers.dev` 하위 도메인을 정하라고 묻습니다.
3. `AUTH_PEPPER`를 자동으로 만들고, 넘겨받은 키들과 인증 메일 보내는 주소(`MAIL_FROM`)를 비밀값으로 넣습니다. 보내는 주소가 Gmail이면 앱 비밀번호를, 아니면 Resend 키를 묻습니다.

그다음부터는 `npm run deploy`만 하면 됩니다.

### 이메일 인증 메일

두 가지 중 하나로 보냅니다. 둘 다 무료입니다.

**Gmail로 보내기 (도메인 없이)**: 내 Gmail 주소로 보냅니다(하루 약 500통).

1. 보낼 구글 계정에서 **2단계 인증**을 켭니다(앱 비밀번호를 만들려면 필요).
2. https://myaccount.google.com/apppasswords 에서 앱 비밀번호(16자리)를 만듭니다.
3. `setup`에서 보내는 주소에 `레시퐁 <내계정@gmail.com>`, 이어서 앱 비밀번호를 넣습니다. 직접 넣으려면 `npx wrangler secret put MAIL_FROM`, `npx wrangler secret put GMAIL_APP_PASSWORD`.

Workers가 smtp.gmail.com:465에 암호화 연결로 붙어 보냅니다. 구글 계정 비밀번호를 바꾸면 앱 비밀번호도 풀리니 새로 만들어 넣어 주세요.

**Resend로 보내기 (내 도메인이 있을 때)**: 무료 하루 100통·월 3,000통.

1. https://resend.com 가입 → **Domains**에서 내 도메인을 추가하고, 안내하는 DNS 레코드를 넣습니다(도메인이 Cloudflare에 있으면 버튼 하나로 자동 설정).
2. **API Keys**에서 키를 만듭니다(Sending access).
3. `setup`에서 보내는 주소에 `레시퐁 <no-reply@내도메인.com>`, 이어서 Resend 키를 넣습니다.

- 보내는 주소와 앱 비밀번호(또는 Resend 키)가 둘 다 있어야 켜집니다. 둘 다 있으면 Gmail을 먼저 씁니다. 없으면 이메일 인증 없이 가입만으로 쓸 수 있습니다(나중에 켜면, 그때까지 인증하지 않은 계정은 다음 접속 때 인증해야 합니다).
- 무료 한도를 넘지 않게 하루 90통에서 멈추고, 한 사람에게는 1분에 1통, 하루 5통까지만 보냅니다.
- 메일이 안 가는 지인은 관리 화면의 사용자 시트에서 **인증한 것으로 처리**할 수 있습니다.
- 로컬에서는 `.dev.vars`의 `MAIL_MOCK=1`로 메일을 보내지 않고 인증 링크를 화면에 띄웁니다.

### GitHub에 올리면 자동 배포 (GitHub Actions 없이)

Cloudflare 대시보드 → Workers & Pages → recipong → Settings → **Builds**에서 이 GitHub 저장소를 연결합니다.

- Build command: `npm run build`
- Deploy command: `npx wrangler d1 migrations apply DB --remote && npx wrangler deploy`

이렇게 하면 Cloudflare가 직접 빌드합니다(무료 플랜 포함). `main`에 올리면 배포됩니다.

### 주소가 Cloudflare 로그인 화면으로 막힐 때

계정의 `workers.dev`에 Cloudflare Access가 걸려 있으면 낯선 방문자가 앱에 들어오지 못합니다. Workers & Pages → recipong → Settings → Domains & Routes에서 workers.dev의 Access를 끄거나, 개인 도메인을 연결하세요.

## 설정

`wrangler.jsonc`의 `vars`(공개):

| 이름 | 설명 |
|---|---|
| `GEMINI_MODELS` | 차례로 시도할 Gemini 모델들. 모델이 바뀌면 여기만 고치면 됩니다. |
| `GROQ_MODEL`, `WORKERS_AI_MODEL`, `OPENROUTER_MODEL` | 예비 엔진 모델 |
| `TURNSTILE_SITE_KEY` | 가입 봇 차단(선택). 비밀 키는 `TURNSTILE_SECRET`로 |
| `INSTA_HELPER_URL` | 폰서버 인스타 도우미 주소(선택, [helper/README.md](helper/README.md)) |
| `APP_URL` | 메일 속 링크 주소(개인 도메인을 붙였을 때). 비우면 접속한 주소를 씁니다. |

비밀값(`npx wrangler secret put 이름`):

| 이름 | 필수 | 설명 |
|---|---|---|
| `AUTH_PEPPER` | ✔ | 비밀번호 해시용. `setup`이 만들어 줍니다. **한 번 정하면 바꾸지 마세요.** 바꾸면 모든 비밀번호가 맞지 않게 됩니다. |
| `ADMIN_EMAILS` |  | 관리자 이메일(쉼표 구분). 이 이메일로 가입해 **인증을 마치면** 관리자가 됩니다. 없으면 첫 가입자가 관리자입니다. |
| `MAIL_FROM` | 권장 | 인증 메일 보내는 주소. 예: `레시퐁 <내계정@gmail.com>`. 저장소에 이메일이 공개되지 않게 비밀값으로 둡니다. |
| `GMAIL_APP_PASSWORD` | 권장 | `MAIL_FROM`의 Gmail 계정 앱 비밀번호. 이메일 인증·비밀번호 찾기 메일 |
| `RESEND_API_KEY` |  | Gmail 대신 Resend로 보낼 때(내 도메인 필요) |
| `GEMINI_API_KEY` | 사실상 ✔ | https://aistudio.google.com/apikey |
| `GROQ_API_KEY`, `OPENROUTER_API_KEY` |  | 예비 AI |
| `YOUTUBE_API_KEY` | 권장 | 설명란과 영상 길이를 안정적으로 읽습니다(무료 하루 1만 건). 없으면 공개 페이지를 읽는데, 클라우드 IP에서 막히면 영상 길이를 몰라 **일반 계정은 영상 분석을 못 합니다**(설명란·자막 붙여넣기는 됨). |
| `TURNSTILE_SECRET` |  | 가입 봇 차단 |
| `INSTA_HELPER_TOKEN` |  | 폰서버 도우미와 맞춘 토큰 |

## 무료로 버티는 규모와 주의점

- 가장 먼저 닿는 한도는 Gemini 하루 요청 수입니다. 첫날 [AI Studio의 rate limit 화면](https://aistudio.google.com/rate-limit)에서 내 프로젝트 숫자를 확인하고 **관리 → 하루 AI 예산**을 그보다 조금 낮게 맞추세요.
- Gemini 무료 티어 입력은 구글 제품 개선에 쓰일 수 있습니다. 가입 화면에 그렇게 안내하고 있습니다.
- 유튜브 URL 직접 분석은 Gemini의 프리뷰 기능입니다. 무료 티어는 하루 8시간 분량이고 공개 영상만 됩니다. 막히면 설명란·자막 붙여넣기로 자동 전환됩니다.

## 폴더
